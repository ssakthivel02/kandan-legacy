உள்ளூர் தரவை நீக்குதல்

Delete local data created by the Saravana Bhava Android app or this website. The current release has no cloud account or server profile to delete.

Android app identity

App: Saravana Bhava – Murugan Bhakti
Package: com.saravanabhava.murugan
Version: 1.1.0

The app may store bookmarks, recently viewed items, reading progress, font preferences, notification preferences, quiz scores, rewards, achievements and an optional local profile name on the device.

Option 1 — Inside the app

  1. Open Saravana Bhava.
  2. Open Settings.
  3. Choose Delete All Data.
  4. Confirm the action and restart the app.

If this option is not visible in the installed build, use Android Settings instead.

Option 2 — Android Settings

  1. Open Android Settings.
  2. Choose Apps.
  3. Select Saravana Bhava – Murugan Bhakti.
  4. Open Storage.
  5. Choose Clear Storage or Clear Data.

Option 3 — Uninstall

Uninstalling the app removes the app and its locally stored data. Android backup is disabled for the validated build configuration.

Website browser-local data

The website may store favourites, notes, language preference, reading preference or offline cache data in the current browser profile. This information is not associated with a Saravana Bhava user account.

  1. Open Personal Data Tools and use the available local reset or deletion controls.
  2. For offline cache problems, open Technical Support and clear runtime caches first.
  3. To remove everything for the website, use the browser's site-data controls for omsaravanabhava.org.

No cloud account deletion request is required

The current Android app and website do not provide a Saravana Bhava user-account system. Therefore there is no cloud profile, password, subscription record or server-hosted personal note collection to delete.
