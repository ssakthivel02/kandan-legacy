App does not open

Restart the phone, confirm the installed version, and record the exact crash or blank-screen behaviour. Do not reinstall until bookmarks or notes have been considered.

Tamil narration is unavailable

Update the Android text-to-speech engine, install a Tamil voice where available, restart the app and try a short devotional passage first.

Bookmark or progress problem

Record the content title, action and restart result. Local data can be reset through the app or Android Settings, but deletion is irreversible.

Temple information looks wrong

Include the temple name, field, current value, proposed correction and an official or authoritative source. Do not overwrite needs-review data from memory.

Guided Search result is missing

Provide the Tamil, English or transliterated query, expected content title and actual result. Guided Search uses bundled local records and does not invent missing content.

Android app issue report

Include all of the following:

  • screen or content title
  • button or action performed
  • expected result
  • actual result and visible error
  • Android version and device model
  • app version and versionCode
  • whether the issue remains after an app restart
  • a screenshot that contains no private information

Safe website quick fixes

Use the smallest recovery action first.

Old homepage or old styles

Reload once. When an old service-worker cache persists, clear only runtime/data caches before removing the full site storage.

Page did not refresh

Reload the current route after cache clearing. A hard refresh may be required when a proxy or CDN retains an earlier asset.

Missing or renamed route

The 404 page checks an exact alias registry, then suggests related governed routes without fuzzy automatic redirects.

Open directory

Offline page unavailable

Open the site once online so core routes and assets can enter the PWA cache. Optional routes may still require a network connection.

Open offline guide

Notes or favourites missing

Browser-local data is tied to the browser profile and site storage. Restore a prior export where available.

Personal data tools

Content looks incorrect

Do not overwrite a source-controlled text from memory. Prepare a correction with page, edition and evidence.

Prepare correction

Escalation information

Include the page or app screen, approximate time, browser or device, online/offline state, visible error, expected result, steps to reproduce and whether a restart or cache refresh changed the behaviour. Never include passwords, private notes or unnecessary personal data.
