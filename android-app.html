Support

Report the screen, action, expected result, actual result, Android version and screenshot to ssakthiveluk02@gmail.com. Never send passwords or private documents.

Local data deletion

Use App Settings → Delete All Data, Android Settings → Apps → Saravana Bhava → Storage → Clear Data, or uninstall the app. There is no cloud account to delete.
