Privacy Policy

Website: Om Saravana Bhava
Android app: Saravana Bhava – Murugan Bhakti
Package: com.saravanabhava.murugan

Last updated: 28 July 2026

Android app information Local data deletion

Plain-language summary

  • No Saravana Bhava user account is required.
  • No advertising SDK or third-party analytics backend is used by the current Android release.
  • Bookmarks, preferences, progress and optional profile information stay on the user's device.
  • Guided Search uses bundled local content rather than a remote generative-AI service.
  • Tamil narration uses the device text-to-speech service.
  • External maps, websites or approved remote audio are opened only when the user chooses them.

Android app privacy

The current Android app has no user-account system and does not operate an advertising, behavioural-tracking or third-party analytics backend.

Data stored locally

Bookmarks, recently viewed content, reading streak, font preference, notification settings, quiz scores, rewards, achievements and an optional local profile name may be stored on the device. They are not uploaded to a Saravana Bhava account or server. Android backup is disabled for the validated app configuration.

Internet, audio, narration and maps

Core devotional reading and Guided Search use bundled local content. Internet access may be used when the user opens this website, the privacy/support pages, an external map or an approved remote audio source. Tamil narration uses the device text-to-speech service. External services have their own privacy policies.

Notifications

When enabled, daily reminders are scheduled locally on the device. The app requests notification permission where Android requires it.

Data deletion

Users can delete local data through the app Settings screen, clear the app's Android storage, or uninstall the app. There is no cloud account record to delete. See the complete local data deletion instructions.

Children, ads and purchases

The devotional and cultural content is intended for general audiences. The app does not knowingly collect children's personal information and does not contain advertising or in-app purchases.

Website privacy and local preferences

No account or server profile is used by the website preference controls. Browser-local choices, favourites or notes stay within that browser profile unless the user exports them.

Offline caching may store website assets and selected content in the browser. Users can remove these through Personal Data Tools, the support diagnostics, or the browser's site-data settings.

The Mantra Practice stores only local preferences and completed-session metadata (mantra identity, bounded target and completion time). It does not store exported sacred text, transmit practice activity, create an account or use analytics. Its page-level clear control removes its history.

The Daily Murugan Darshan stores only the selected morning/evening preference and bounded completion metadata (local date, path identity, period and completion time). It does not request birth details, location, notifications or an account; exports and shared summaries exclude sacred text and personal notes.

External services

When a user deliberately opens a map, external temple website, email link, approved remote media or device text-to-speech service, that external provider may process information under its own privacy terms. Om Saravana Bhava does not control those independent services.

Changes and contact

Material privacy changes will be published on this page with an updated date.
