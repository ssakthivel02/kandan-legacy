# Phase 11 — Premium Rollout Production Gate

This directory is regenerated by `tools/phase-11/validate_premium_rollout.py` during CI.

The gate verifies:

- all Phase 6–10 target pages exist in `_site`;
- each page carries its scoped phase body class;
- each page references global CSS, global JavaScript and its phase stylesheet exactly once;
- the inline Vel–Mayil emblem, language control and AI Guide runtime markers exist;
- the Discovery workspace retains a resilient fallback;
- enhanced pages have one `<main>`, one `<title>` and no duplicate IDs.

The gate does not claim formal WCAG certification or field Core Web Vitals.
